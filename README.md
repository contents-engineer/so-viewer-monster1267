# HAUS NOWHERE — 성수 2041 · DS2 산악 월드

**HAUS NOWHERE SEOUL**(81 m 사옥)과 **FaceArch**(31 m 필로티 조형 건물)를 중심으로 구축한 두 가지 3D 월드 아카이브 뷰어입니다.

1. **성수 2041 (`ver=seongsu`)**: 성수동 뚝섬로 블록(붉은 벽돌 공장·공방·2호선 고가·은행나무·전선), 자연 침식 포켓(현무암·산악 이끼·검은 물웅덩이), 근미래 레이어(청록 LED 차선·유리 버스 키오스크·자율주행 로보택시·순찰 드론) 결합 월드
2. **DS2 산악 고원 (`ver=ds2`)**: 양쪽으로 층리 대암벽(이끼 선반 + 회색 단애 + 세로 걸리)이 솟고 상류로 갈수록 V자로 겹쳐지는 빙하 U자 계곡, 이끼·황록 풀이 덮인 계곡 바닥의 회색 표석 들판과 개울, 북북동 암벽 너머 역광 태양 헤이즈, 북측 협곡 산악 고가교, 카이랄 개척 트러스 브리지·릴레이 비콘·홀로그램 이정표 결합 월드

- 출하되는 모든 외부 텍스처·모델·HDRI는 **Poly Haven CC0** 이며, 한글 간판 생성용 글꼴은 **SIL OFL 1.1** 입니다.

## 1. 실행 및 URL 옵션

```bash
npm start          # http://localhost:4173
npm run start:lan  # 같은 Wi-Fi 기기에서 http://<PC IP>:4173
```

- **성수 2041 (기본)**: `http://localhost:4173/` 또는 `http://localhost:4173/nowhere`
- **DS2 산악 월드**: `http://localhost:4173/?ver=ds2` 또는 `http://localhost:4173/nowhere-mountain`
- **인트로 생략 + 특정 카메라/기상/시각 진입**: `http://localhost:4173/?ver=ds2&noIntro=1&cam=lot&weather=rain&time=21:30` (`weather` = `overcast` · `rain` · `snow`, 옛 값 `dusk` · `night` 는 시각 18:30 · 21:30 으로 적용 / `time` = `0`~`24` 또는 `HH:MM`)
- **모바일 품질 강제 테스트**: `http://localhost:4173/?tier=mobile`

| 조작 / 단축키 | 동작 |
|---|---|
| `성수 2041` / `DS2 산악` (상단 우측) | 두 월드 배경 버전 즉시 전환 |
| `기상` · `시간` (하단 좌측) | 기상 `흐림` · `비(타임폴)` · `눈` 과 시간(0~24시 시각 슬라이더 · `낮 14:00` · `황혼 18:30` · `밤 21:30`)을 따로 골라 조합(예: 비 오는 밤, 눈 오는 황혼). 해는 시각에 따라 움직이고(06:00 일출 · 18:30 일몰, 밤에는 달빛), 14:00 은 각 월드의 기준 조명 |
| `카메라 프리셋` (하단 우측) | 6종 시점 이동 (`거리/개척로` · `조감` · `고가 하부/협곡 상류` · `밤거리/산악의 밤` · `노면 근접/개울 근접` · `자연 포켓/이끼 포켓`), DS2 는 7번째 `빙하 계곡`(상류 개울 둑에서 겹쳐지는 층리 암벽) 추가 |
| `Esc` | 조작 안내 · 모달 닫기 → 투어(인트로 · 건물 비행) 종료. 보행 시점 중에는 마우스 고정 해제 → 보행 시점 해제 |
| `Enter` | 모달에서 강조된(또는 포커스된) 버튼 선택 |
| `?` / `조작 안내` 버튼 | 공통 · 카메라 시점 · 보행 시점 조작 키를 한 장으로 보여 주는 안내 열기/닫기 |
| `P` (키보드 없는 기기는 주소에 `?stats=1`) | 오른쪽 위 성능 표시 켜기/끄기: FPS · 평균/최대 프레임 시간, 그리기 호출 · 삼각형, 올라간 텍스처 수 · 메모리 추정, JS 힙(Chrome 만), 그리기 해상도 · DPR · 기기 등급(desktop/mobile), GPU 이름. 왼쪽 띠 색: 50 fps 이상 초록 · 30 이상 노랑 · 그 아래 빨강 |
| `V` / `보행 시점` 버튼 | 지면 위 1.7 m 눈높이 보행 시점 토글. `WASD` 걷기(5 m/s), `Shift` 누른 채 달리기(10 m/s), `Space` 점프(약 1.1 m — 낮은 바위·턱을 넘거나 그 위에 올라섬), `↑`/`↓` 올려다보기·내려다보기(±80°), `←`/`→` 좌우로 돌아보기, 화면 클릭 시 마우스 시선 고정(마우스만 움직여 둘러보기, 화면 중앙 조준점 표시, `Esc` 해제), 마우스 드래그로도 제자리에서 둘러보기. 지형 기복을 따라 걷고, 건물·바위·전주 등 장애물과 50° 넘는 급경사는 통과하지 못함(벽을 따라 미끄러짐), 0.5 m 넘는 낙차에서는 떨어짐 |
| `투어 시작` 버튼(첫 방문 시 자동) | 인트로 비행 → 「어떤 건물로 이동하시겠습니까?」(하우스노웨어 성수 · 하우스노웨어 몽골) → 건물 정면 비행 → 성수: 「입장하시겠습니까?」 예 → 실내 1F 로비 / 몽골: 「준비중입니다」. 도착 모달에서 `하우스노웨어 몽골로 이동`(성수) · `하우스노웨어 성수로 이동`(몽골)을 고르면 다른 건물 정면으로 바로 비행. 인트로 중 아무 입력은 건물 선택으로 건너뛰고, `Esc` 는 투어 종료 |
| `건물 이동` 버튼 | 건물 선택 모달부터 다시 시작 |
| 실내(성수 B1F · 1F · 12F · 13F) | 1F 로비에서 보행 시점으로 시작(이동 · 달리기 · 점프 · 충돌 그대로). 왼쪽 위 층 버튼(`13` · `12` · `1` · `B1`) 또는 엘리베이터 문 앞 「층 선택」으로 층 이동, `이 층 둘러보기` 는 첫 볼거리로 화면 전환(어두워졌다 밝아짐)한 뒤 나머지를 차례로 비행하며 자막, 끝까지 보면 마지막 지점에서 보행 시점으로 복귀(아무 입력으로 멈추면 그 자리에 머묾). 창밖은 그 층 높이의 외관 풍경(기상 · 시간 반영, 지하 제외), 밤에는 실내 조명이 따뜻해짐. 1F 디스플레이는 월드 시각(시간 슬라이더) · 기상. `밖으로 나가기` 또는 1F 정문 쪽 출구에서 외관 HAUS 정면으로 복귀 |

## 2. 빌드 및 검증 파이프라인

```bash
# 1) Poly Haven CC0 에셋·OFL 글꼴 다운로드 및 SHA-256 검증 + Three.js r170 JSM 애드온 벤더링
npm run nowhere:fetch

# 2-A) 성수 2041: Blender 씬 조립 + 마스크·Cycles AO 베이킹 + GLB·layout.json·렌더 내보내기 및 최적화
npm run nowhere:build
npm run nowhere:optimize

# 2-B) DS2 산악 월드: Blender 씬 조립 + 마스크·Cycles AO 베이킹 + GLB·layout.json·렌더 내보내기 및 최적화
npm run nowhere:ds2:build
npm run nowhere:ds2:optimize

# 2-C) 성수 실내(B1F · 1F · 12F · 13F): 층 껍데기 + 실내 에셋 축척 · 배치 · 감축 · 바닥 AO → 데스크톱 · 모바일 GLB · inner-layout.json · HDRI (일부 층만: NW_FLOORS=b1,12)
npm run nowhere:inner:build
npm run nowhere:inner:optimize

# 3) 단위·스키마·자산 예산·금지어 검증 테스트 (node:test)
npm test
```
