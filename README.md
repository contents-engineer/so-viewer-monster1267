# HAUS NOWHERE — 성수 2041 · DS2 산악 월드

**HAUS NOWHERE SEOUL**(81 m 사옥)과 **FaceArch**(31 m 필로티 조형 건물)를 중심으로 구축한 두 가지 3D 월드 아카이브 뷰어입니다.

1. **성수 2041 (`ver=seongsu`)**: 성수동 뚝섬로 블록(붉은 벽돌 공장·공방·2호선 고가·가로수)을 2041년 모습으로 그린 월드. 방향은 세 가지입니다. **복원**(벽돌 세척 · 전신주와 전선 지중화 · 물탱크·실외기·광고판·내려진 셔터 철거), **녹화**(담쟁이 · 수직정원 · 지붕 태양광과 옥상정원 · 가로수 · 포켓 공원), **새 층**(2호선 고가 위 유리 튜브와 열차 · 스카이브리지 2개 · 신축 유리 타워 4동과 풍력 · 태양광 노면과 청록 발광선 · 투명 키오스크 · 카페 테라스). 기본 기상은 맑음이고, 자율주행 포드 · 튜브 열차 · 배송로봇 · 소포 드론 · 풍력 회전자가 `layout.movers` 경로를 따라 움직입니다. 20 초에 한 번 뚝섬로에서 흰 날으는 로드스터가 분사로 떠올라 배럴 롤 뒤 지붕 너머로 날아가거나(A) 정차 포드 두 대를 킥플립으로 뛰어넘어 착지합니다(B). 로드스터는 데스크톱 · 태블릿에서만 보입니다
2. **DS2 산악 고원 (`ver=ds2`)**: 양쪽으로 층리 대암벽(이끼 선반 + 회색 단애 + 세로 걸리)이 솟고 상류로 갈수록 V자로 겹쳐지는 빙하 U자 계곡, 이끼·황록 풀이 덮인 계곡 바닥의 회색 표석 들판과 개울, 북북동 암벽 너머 역광 태양 헤이즈, 북측 협곡 산악 고가교, 카이랄 개척 트러스 브리지·릴레이 비콘·홀로그램 이정표 결합 월드

- 출하되는 모든 외부 텍스처·모델·HDRI는 **Poly Haven CC0** 이며, 한글 간판 생성용 글꼴은 **SIL OFL 1.1** 입니다.

## 1. 실행 및 URL 옵션

```bash
npm start          # http://localhost:4173
npm run start:lan  # 같은 Wi-Fi 기기에서 http://<PC IP>:4173
```

- **월드 선택 화면**: `http://localhost:4173/` — 왼쪽 성수 2041 · 오른쪽 DS2 산악 중 하나를 고르면 로딩 → 인트로 → 방식 고르기(가이드 투어 · 직접 걷기 · 자유 시점). 새로 고침하면 다시 선택 화면
- **성수 2041 바로가기**: `http://localhost:4173/nowhere` 또는 `http://localhost:4173/?ver=seongsu` (선택 화면 없이 인트로부터)
- **DS2 산악 월드 바로가기**: `http://localhost:4173/nowhere-mountain` 또는 `http://localhost:4173/?ver=ds2`
- **방식 지정**: `mode=guide|walk|free` (예: `http://localhost:4173/?ver=ds2&noIntro=1&mode=walk` — 인트로 · 방식 고르기 없이 직접 걷기). `noIntro=1` 이나 `cam` · `weather` · `time` · `at` 이 있으면 지금처럼 인트로 없이 자유 시점
- **같은 자리 진입**: `at=x,y,z&look=x,y,z` (카메라 위치 · 시선 목표, 소수 둘째 자리 — 건물 카드 「이 자리 그대로 …」가 만드는 주소, 사진 모드 `링크 복사` 는 여기에 `time` · `weather` · `fov` 를 더함. `fov=20`~`90`(정수, 그 밖 · 소수는 무시)은 시작 방식이 자유 시점일 때 처음 화면의 화각 — 프리셋 · 보행으로 바꾸면 그쪽 화각, 월드 전환 주소에서는 지움. 예: `http://localhost:4173/nowhere?ver=ds2&mode=walk&at=-105.12,1.7,50.2&look=-95.12,1.7,50.2`). 인트로 없이 그 방식(없으면 자유 시점)으로 그 자리 — 보행이면 지형 높이에 맞춰 서고(장애물 안이면 6 m 안 가장 가까운 빈 자리), 자유 시점은 지면 아래면 지면 위로(시선 방향은 그대로). 숫자 셋이 아니거나 장면 밖(±2000 m)이면 무시하고 기본 시점, look 이 없을 때도 기본 시점
- **인트로 생략 + 특정 카메라/기상/시각 진입**: `http://localhost:4173/?ver=ds2&noIntro=1&cam=lot&weather=rain&time=21:30` (`weather` = `clear`(성수 기본) · `overcast` · `rain` · `snow`, 옛 값 `dusk` · `night` 는 시각 18:30 · 21:30 으로 적용 / `time` = `0`~`24` 또는 `HH:MM`)
- **2041 골목 시점으로 진입**: `http://localhost:4173/?noIntro=1&cam=future` (성수 전용. 하단 카메라 프리셋의 `2041 골목` 버튼과 같은 시점)
- **품질 · 기기 강제 테스트**: `http://localhost:4173/?tier=mobile`(휴대폰 — 날으는 로드스터 없음) · `?tier=tablet`(모바일 등급 + 태블릿 — 로드스터 보임) · `?tier=desktop`


### 성수 히어로 렌더(`public/assets/nowhere/renders/hero-*.webp`) 다시 만들기

- 출하 WebP 7장(1280 × 720, git 추적)이 기준입니다. `npm run nowhere:build`는 이 파일을 건드리지 않습니다.
- 원본은 웹 캡처 PNG `build/nowhere/renders/hero-<id>.png`(git 무시)입니다. Blender 무드에는 맑음이 없어 2041 모습은 웹에서 찍습니다.
- 절차
  1. `npm start` 후 데스크톱 Chrome 에서 뷰포트를 **1600 × 900**(DPR 1)로 맞춥니다.
  2. `http://localhost:4173/nowhere?noIntro=1&cam=<id>&time=14`를 엽니다(밤거리는 `cam=night&time=21.5`). `nowhere.html`로 열면 쿼리가 사라지니 `/nowhere`를 씁니다. 기상은 기본(맑음)입니다.
  3. 3초쯤 기다려 기상 전환이 끝나면, **UI 없이 캔버스만** 저장합니다. 개발자 도구 콘솔에서 그레인을 끄고 이동체 시각을 고정해 한 프레임을 그린 직후 캔버스를 읽습니다(DOM 위 버튼 · 성능 표시는 캔버스에 들어가지 않습니다).

     ```js
     const app = __NW_APP, wm = await import('/src/nowhere/world.js'), t = 30;   // t: 근경을 포드가 가리지 않는 시각
     app.post.gradePass.uniforms.uGrain.value = 0;
     app.world.uniforms.uTime.value = t; wm.updateMoverActors(app.world.moverActors, t);
     app.world.followSun(app.camera); app.post.composer.render();
     Object.assign(document.createElement('a'), { href: app.renderer.domElement.toDataURL('image/png'), download: 'hero-<id>-1600.png' }).click();
     ```
     `t = 30` 에는 날으는 로드스터 B 가 거리 시점 앞(약 47 m) 정차 포드 쪽으로 뛰어오른다. 로드스터를 빼려면 두 대가 모두 숨는 시각을 고른다(`layout.movers` 의 로드스터 `phase` + `visible` 밖 — 지금 값으로 A 0 … 16.5 s, B 20 … 39.1 s, 40 s 주기). 정차 포드 두 대(뚝섬로 x −67 · −73)는 시각과 상관없이 서 있다.
  4. 1600 × 900 PNG 를 **1280 × 720**으로 줄여 `build/nowhere/renders/hero-<id>.png`로 둡니다.
     `uv run --with pillow python -c "from PIL import Image; Image.open('hero-<id>-1600.png').resize((1280, 720), Image.LANCZOS).save('build/nowhere/renders/hero-<id>.png')"`
  5. `npm run nowhere:build -- -- --hero-from-captures`로 WebP 를 다시 만듭니다. 원본이 없는 장은 건너뛰고 경고만 냅니다(그 WebP 는 그대로).
- 파일 이름(`<id>` = 카메라 프리셋): `hero-street` · `hero-aerial` · `hero-viaduct` · `hero-night`(21:30) · `hero-ground` · `hero-lot` · `hero-future`.
  웹은 월드 선택 화면 · 로딩 화면 배경(`hero-future`, DS2 는 `nowhere-ds2/renders/hero-valley`)만 직접 씁니다. 나머지는 `layout.json` 앵커 · 카메라의 `render` 메타데이터입니다.
