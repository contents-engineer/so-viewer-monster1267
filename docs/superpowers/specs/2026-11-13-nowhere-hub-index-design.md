# HAUS NOWHERE — 카테고리 표지 · 아카이브 목록 설계

날짜: 2026-11-13 · 범위: 두 월드(성수 2041 · 산악) 외관 + HAUS 실내

## 1. 목표

두 허브 구조(제안)의 남은 두 장치를 지금 있는 것 위에 얹는다.

1. **카테고리 표지**: ◇ 이동 스팟을 그 자리에 있는 것의 종류로 구분한다(색 · 글자).
2. **아카이브 목록**: 위 막대 `목록` 버튼(`L`)으로 건축 · 전시물 · 제품 전체를 한 패널에서 보고, 고르면 그 감상으로 바로 간다.

## 2. 카테고리

| 카테고리 | id | 글자 | 해당 스팟 |
|---|---|---|---|
| 건축 | `architecture` | `A` | 외관 건물 스팟 중 `kind: 'view'`(건물 기록 카드가 뜨는 곳) |
| 전시물 | `exhibit` | `E` | 실내 층 둘러보기 지점(`kind: 'view'` · 실내) |
| 제품 | `product` | `P` | 제품 스팟(`kind: 'product'`) |
| 이동 | `move` | `→` | 정문 `entrance` · 엘리베이터 `elevator` · 출구 `exit` |

- 판정은 순수 함수 `spotCategory(spot)` 한곳. 표지는 `data-category` 로 CSS 가 색과 글자를 정한다(가까운 단계의 동그라미 안 글자, 먼 단계 ◇ 는 테두리 색만).
- 색은 `--nw-cat-*` 토큰(다크 배경 대비 4.5:1 이상 글자).

## 3. 아카이브 목록

- **데이터**: 새 파일을 만들지 않는다 — 한 코드 모듈 `hub-index.js`(순수)가 지금 있는 출처에서 목록을 만든다(같은 내용을 두 곳에 적지 않게).
  - 건축: `archive.js` 건물 기록(record.json · facearch.json) — 제목, 자리 `<월드 이름> · 외관`.
  - 전시물: inner-layout `floors[].exhibits` — 제목, 자리 `HAUS 성수 <층>`(products.js `floorCrumb` 표기), 설명.
  - 제품: products.json 진열(`floorDisplays` — 진열에 있는 것만) — 이름, 자리 `HAUS 성수 1F`.
  - 문구는 출처 값 그대로.
- **화면**: 위 막대 오른쪽 `목록` 버튼(`L` 키 표시) → 왼쪽 서랍 패널 `ARCHIVE INDEX · 아카이브 목록`, 카테고리 묶음(이름 · 개수 · 카테고리 색 점), 항목 행(제목 · 자리). 닫기 `×` · `Esc` · `L` · 바깥 클릭. 휴대폰은 화면 전체.
- **고르기(가기)**: 항목을 누르면 패널을 닫고
  - 건축 → 건물 감상(`openArchive(id)`) — 외관 · 실내 어디서든(나가면 그 자리).
  - 전시물 → 실내가 아니면 들어가고(`interior.enter`), 다른 층이면 그 층으로(`goToFloor`), 그다음 전시물 감상.
  - 제품 → 같은 방식으로 1F 에서 제품 감상.
  - 이동 중(인트로 · 방식 고르기 · 비행 · 실내 busy · 감상 중)에는 목록 버튼이 막힌다(버튼 자리에 이유 `지금은 목록을 열 수 없습니다` 대신 버튼을 흐리게 + title).
- 목록은 처음 열 때 출처를 받는다(건물 기록 · inner-layout · products.json — 이미 받았으면 그대로).

## 4. 예산 · 기기

DOM 만(그리기 0). 키보드 없는 기기는 버튼. 터치 44 px.

## 5. 안내 · 문서 · 시험

- 조작 안내 공통 묶음에 `L` 한 줄, 보행 묶음 ◇ 스팟 줄에 카테고리 색 · 글자. 1600 × 900 첫 화면 배치 유지(help 시험 (l)).
- README 기능 표 · 조작 표.
- 순수: `spotCategory`(모든 스팟 종류), `hubIndex`(세 출처 → 묶음 · 개수 · 자리 · 문구 그대로, 진열에 없는 제품 제외), `goPlan(item, state)`(지금 상태 → 할 일: enter / goToFloor / open).
- 브라우저: 외관에서 전시물 고르기(들어가서 층 이동 후 감상), 실내 다른 층에서 제품, 실내에서 건물, 표지 색 · 글자 캡처, 휴대폰 패널.
