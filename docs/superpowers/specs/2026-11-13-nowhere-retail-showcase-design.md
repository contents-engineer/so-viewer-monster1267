## 1. 에셋 파이프라인 (`npm run nowhere:products`)

- 입력: 원본 폴더(기본 위 경로, 환경 변수 `PRODUCT_SRC` 로 바꿀 수 있음). 저장소 밖 원본은 커밋하지 않고, 결과만 `public/assets/products/` 에 둔다.
- 출력(제품마다 두 파일):

| 파일 | 쓰임 | 삼각형 | 텍스처 | 목표 크기 |
|---|---|---|---|---|
| `products/<id>.glb` | 데스크톱 · 태블릿 감상 모드 | ≤ 80 K | ≤ 1024, WebP | ≤ 3 MB |
| `products/<id>-lite.glb` | 진열(모든 등급) · 휴대폰 감상 모드 | ≤ 20 K | ≤ 512, WebP | ≤ 0.8 MB |

- 처리: 정리(prune · dedup · weld) → 단순화(meshopt simplifier, 경계 고정, 오차 상한) → 텍스처 크기 · WebP → meshopt 압축. `KHR_texture_basisu` 등 뷰어가 못 읽는 확장은 결과에 남기지 않는다. 투명 재질(렌즈 · 코받침)의 알파 모드는 유지한다.
- Veggie Oat 의 `WorldGridMaterial` 메시는 원본 확인 뒤(언리얼 기본 격자 재질 — 제품 일부가 아니면) 제거한다.
- 단순화 품질은 감상 모드에서 눈으로 확인한다(경첩 · 코받침 · 렌즈 테 모양이 무너지지 않을 것). 상한을 지키지 못하면 보고하고 상한을 함께 정한다.

## 2. 제품 목록 (`public/assets/products/products.json`)

```json
{
  "products": [
    {
      "id": "kant",
      "name": "Kant",
      "category": "eyewear",
      "glb": "assets/products/kant.glb",
      "liteGlb": "assets/products/kant-lite.glb",
      "sizeMm": { "width": 157, "length": 154, "height": 40 },
      "materials": ["렌즈", "플라스틱 프레임", "메탈"],
      "description": "",
      "collection": "",
      "color": ""
    }
  ],
  "displays": [
    { "floor": "1", "product": "kant", "pos": [x, 0, z], "yaw": 0 }
  ]
}
```

- `sizeMm` 은 원본 경계 상자에서 잰 값(mm, 반올림). `materials` 는 원본 재질 이름을 보고 한국어로 적는다.
- 빈 문자열 필드는 화면에 나오지 않는다.
- `displays` 는 층별 진열 자리(실내 층 좌표, 받침대 바닥 중심). 제품 · 진열을 늘릴 때는 GLB 를 넣고 이 파일만 고친다.

## 3. 1F 진열

- 받침대 3개를 일렬로(간격 약 2.5 m), 정문 진입 동선 옆에 둔다. 기존 전시물 · 둘러보기 지점 · 엘리베이터 · 출구 영역과 1.5 m 이상 떨어뜨린다(자리는 구현 중 실내 점유 격자로 확인).
- 받침대: 폭 0.5 · 높이 1.05 · 깊이 0.5 m 의 무광 석재 기둥 + 위에 투명 유리 덮개(0.42 × 0.28 × 0.42 m, 한 번에 그리기 · 그림자 없음) + 윗면의 은은한 발광 판(실제 조명 없이 자체 발광으로 — 조명 수를 늘리지 않는다).
- 제품: `-lite` 를 실제 크기로 받침대 위(덮개 안, 눈높이 약 1.15 m)에 앉히고 정면이 진입 쪽을 보게 한다.
- 받침대는 보행 장애물이다(실내 점유 격자에 더한다). 제품 · 덮개는 장애물 계산에서 받침대에 포함된다.
- 진열 메시 · 받침대는 웹에서 런타임으로 만든다(실내 Blender 빌드 · GLB 변경 없음). 1F 를 처음 보여 줄 때 불러온다.

## 4. 고르기

- **보행 스팟**: 받침대 앞 1.2 m 에 제품 스팟(`kind: 'product'`, 이름 = 제품 이름, look = 제품). 도착하면 감상 모드를 연다.
- **클릭 · 탭**: 실내에서 제품 · 받침대를 클릭 · 탭(끌기 없이)하면 연다. 보행 중 마우스 고정 상태에서는 조준점이 제품 위에 있을 때 클릭으로 연다.
- **이름표**: 제품에서 4 m 안이면 받침대 위에 이름표(DOM, '자세히 보기')를 띄운다. 누르면 연다.

## 5. 감상 모드 (`showcase.js`)

- **무대**: 별도 장면. 어두운 청회색 배경 + 바닥 원판(부드러운 그림자 대신 그라데이션 원) + 반사용 환경(RoomEnvironment PMREM) + 키 · 필 · 림 조명 3개. 제품은 원점에 세우고 크기에 맞춰 카메라 거리를 정한다.
- **렌더**: 감상 중에는 외관 · 실내 · 후처리를 그리지 않고 이 장면만 그린다(조감 · 실내보다 가볍다).
- **조작**: 드래그 · 한 손가락 = 회전, 휠 · 두 손가락 = 확대(제품 크기 기준 최소 · 최대 거리), 4 초 동안 입력이 없으면 천천히 자동 회전. `←` / `→` 또는 화면의 이전 · 다음 버튼 = 같은 층 진열 순서로 제품 넘기기. `Esc` · `< BACK` = 나가기.
- **화면**: 왼쪽 위 경로 `SUPREME ORIGIN > Retail > HAUS 성수 1F > <제품명>`, `< BACK`. 오른쪽 정보 패널(제품명, 실측 크기 `폭 157 · 길이 154 · 높이 40 mm`, 재질 목록, 비어 있지 않은 설명 · 컬렉션 · 컬러). 아래 작은 조작 안내.
- **고해상도**: 데스크톱 · 태블릿은 열 때 `<id>.glb` 를 받는다(받는 동안 `-lite` 로 먼저 보여 준다). 휴대폰은 `-lite` 만.
- **나가기**: 연 자리 · 시선 · 보행 여부 그대로 돌아온다(보행 스팟 · 마커 · 실내 HUD 복원). 실내 장면 렌더로 돌아간다.
- 감상 중에는 실내 HUD · 이동 스팟 · 보행 안내 · 방식 전환을 숨기고, 모달 · 조작 안내는 그대로 쓸 수 있다.

## 6. 연결

| 모듈 | 바뀌는 점 |
|---|---|
| `products.js` (새, 순수) | 목록 읽기 · 검증, 층별 진열 · 스팟 만들기, 크기 · 재질 문구, 이전 · 다음 순서, 감상 키 해석 |
| `retail-display.js` (새) | 층 진열 만들기(받침대 · 덮개 · 제품 lite), 장애물 등록, 클릭 판정, 이름표 |
| `showcase.js` (새) | 스튜디오 장면 · 카메라 · 조작 · UI · 고해상도 교체 · 나가기 복원 |
| `interior.js` | 층 표시 때 진열 만들기 · 지우기, 점유 격자에 받침대 더하기, 감상 중 숨김 상태 |
| `walk-spots.js` | 실내 층 스팟에 제품 스팟 더하기(`kind: 'product'`) |
| `main.js` | 렌더 루프에서 감상 중이면 감상 장면만, 도착 동작(제품 스팟 → 감상), 감상 중 일시 정지 조건 |
| `help.js` · `README.md` | 제품 진열 · 감상 모드 조작 안내 |
| `package.json` | `nowhere:products` 스크립트 |

## 7. 예산 · 성능

- 1F 진열: 그리기 ≤ +12, 삼각형 ≤ +70 K(받침대 · 덮개 합쳐 그리기 2 + 제품 lite 3 점).
- 실내 진입 추가 다운로드: lite 3 점 ≤ 2.4 MB(데스크톱 · 모바일 공통). 고해상도는 감상 모드에서만.
- FPS ≥ 60(1F 보행 · 감상 모드, 데스크톱 · `&tier=tablet`).
